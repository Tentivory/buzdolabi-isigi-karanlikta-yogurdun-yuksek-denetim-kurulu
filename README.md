# Buzdolabı Işığı Karanlıkta Yoğurdun Yüksek Denetim Kurulu

**Resmi ad:** Buzdolabı Işığının Kapanınca Sönüp Sönmediği ve Yoğurdun Karanlıkta Varlığını Sürdürüp Sürdürmediği Meselesine Dair Yüksek Denetim Kurulu

**Kısa ad:** BI-YDK

**Statü:** Ciddi. Çok ciddi. Hiç komik değil. (Gülerseniz tutanak tutulur.)

## Misyon

İnsanlık bin yıldır yanlış sorular sordu. Biz doğru soruyu sorduk:

> Kapak kapanınca ışık sönüyor mu, yoksa yoğurt karanlıkta bizden habersiz bir medeniyet mi kuruyor?

Bu depo, söz konusu kriz için dünyanın ilk ve tek yüksek denetim yazılımıdır. Bilim insanları şokta. Filozoflar dolaba bakıyor. Yoğurt ifade vermiyor.

## Neden var?

Çünkü birisi kapağı kapattı ve “iş bitti” sandı. İş bitmedi. İş yeni başladı. Işık söndüğünü iddia eden tanıklar var. Işığın kapağın arkasından bize baktığını iddia eden tanıklar da var. Kurul tarafsızdır. Kurul ayrıca çok yorgundur.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Dolap da yoktur. Sorumluluk kabul edilmez.

```bash
git clone https://github.com/Tentivory/buzdolabi-isigi-karanlikta-yogurdun-yuksek-denetim-kurulu.git
cd buzdolabi-isigi-karanlikta-yogurdun-yuksek-denetim-kurulu
python3 kurul.py
```

## Kullanım

```bash
python3 kurul.py --kapak kapali --yogurt 1 --raf orta
python3 kurul.py --kapak acik --yogurt 0 --raf yok
python3 kurul.py --demo
```

Çıktı resmi tutanaktır. Çıktıyı buzdolabına mıknatısla asabilirsiniz. Mıknatıs da denetlenir, sonra.

## Denetim metodolojisi

1. Kapak durumu beyan edilir.
2. Yoğurt adedi sayılır. Sayılamazsa “karanlık istatistik” devreye girer.
3. Işık, kuantum değil, inatçılık ilkesiyle değerlendirilir.
4. Kurul karar verir. Karar bağlayıcıdır. Yoğurt itiraz edemez.
5. Damga basılır. Damgasız tutanak yoğurttur, yoğurt değildir. Cümle böyle kalsın.

## Bilimsel iddia

Kapak kapalıyken ışığın söndüğünü kanıtlamak için kapağı açmak gerekir. Kapağı açınca deney bozulur. Bu yüzden kurul, kanıt yerine tutanak üretir. Bu, metodolojinin zaafı değil, metodolojinin ta kendisidir.
